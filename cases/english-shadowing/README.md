# 英语 Shadowing：从逐句材料到练习反馈

[返回首页](../../README.md)

## 需求

以美式口语发音为目标，把影视或访谈中的短片段整理成逐句材料，结合时间对齐、切片与 Notion 学习卡片，支持跟读、复述和练习反馈。Paul Gruber 是发音学习背景，不代表其参与本项目或认可本方法。

## 成果

必须把三个层次分开看：

| 层次 | 当前状态 |
| --- | --- |
| 方法设计 | 已整理逐句材料、时间对齐、切片、卡片与反馈的学习流程 |
| 已有材料 | 已有《纸牌屋》学习材料和制作技能；本仓库不转载影视、完整字幕或私有学习卡片 |
| 自动制作 | 近期 Peaky Blinders 与 Goggins 的 B 站尝试只完成来源检查或部分学习结构；可编辑媒体和英文字幕获取未完成，全流程未跑通 |

这里没有可报告的发音提升指标，也不把方法设计称为全自动成功。Peaky Blinders 的来源尝试不意味着其语言风格适合美式发音目标，选材还需核对口音。

## 工具环境

方法涉及合法可用的短音视频、逐句英文材料、时间标记、切片工具、Notion 学习卡片和 AI 辅助。具体工具版本与全流程运行记录尚未在本手记中提供，因此这些环节是复现设计，不是已经验证的工具组合。

公开复现建议使用自录或明确授权的短素材。此仓库仅提供 [原创练习示例与素材说明](assets/README.md)，不访问受阻媒体，不索取 Cookie，也不提供私有 Notion 链接。

## 本人和 AI 分工

本人确定发音目标、选择适合的来源、实际跟读和复述，并核对反馈是否对应自己的录音。AI 辅助组织逐句材料、学习结构和制作步骤。时间边界、文本准确性、口音适配与练习反馈仍需要人工检查。

## 实施步骤

以下是可复用流程，尚未证明所有环节已自动完成：

1. **选择合法短素材**：记录来源与使用范围，优先自录或授权片段；为美式目标检查说话人的口音和表达风格。
2. **获得可编辑素材与英文文本**：确认能够合法读取、编辑和使用。若无法获得，在此处停止，不把来源页面存在当成素材可用。
3. **逐句对齐**：给每句标注开始、结束时间，人工试听边界，避免切掉起音或混入下一句。
4. **制作练习单元**：把一句或一个完整意群做成短片段，保留原文、含义、发音关注点和来源记录。
5. **建立卡片**：在自己的 Notion 中记录片段位置、跟读提示、复述问题和练习记录；公开分享时使用去除私有链接的模板。
6. **跟读与复述**：先听原音，再跟读和录音；脱离原文，用自己的话复述意思。
7. **检查反馈**：针对录音核对具体音、重音、节奏或连读问题，再做一次练习。AI 反馈是辅助判断，不能代替可核查的录音或专业发音评价。

## 踩坑修复

- **来源可见不等于可制作**：先检查媒体与英文文本能否合法获取，再投入对齐和切片工作。
- **把部分工作写成全流程完成**：分别记录来源检查、材料获取、对齐、切片、卡片和练习反馈状态；缺一项就明确缺口。
- **从 403 推断登录失败**：把匿名请求和已登录流程分开，未验证的登录态保持“未知”。
- **切片或文本不准确**：逐句试听和校对；自动生成的时间戳与文字不直接当作正确答案。

## 可复用方法和局限

把学习材料做成小单元，每个单元只有一个明确练习目标，并保留来源、文本、时间边界和自己的录音记录。这样可以检查反馈是否具体，也方便重复练习。

自动制作仍依赖素材授权、可编辑文件和可靠文本；本案例尚未验证端到端自动化。学习效果需要连续练习和可比较录音，不能由卡片数量或 AI 的评价直接推导。仓库分享学习方法，不转载完整影视和字幕。
