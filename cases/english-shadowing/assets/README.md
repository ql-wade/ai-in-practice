# 原创练习示例与素材说明

[返回案例](../README.md)

以下句子为本仓库原创示例，不是影视台词，也不是实测成果。没有对应音频，因此不填写虚构时间戳或切片链接。

| 卡片字段 | 示例 |
| --- | --- |
| 英文句子 | I have a small idea. Let's try it today. |
| 中文含义 | 我有一个小想法。今天试试看。 |
| 来源 | 本仓库原创练习句；复现时可自行录音 |
| 开始 / 结束时间 | 待自录后实际标注 |
| 发音关注点 | 试听并比较 small、idea、try、today 的重音与节奏 |
| 跟读任务 | 听自录参考音，再跟读；用录音检查差异 |
| 复述任务 | 用自己的话说明今天准备尝试什么 |
| 反馈记录 | 记录具体差异、判断依据和下一次练习内容 |

可把这些字段复制到自己的 Notion 卡片。目录不附影视媒体、完整字幕、私有 Notion 链接或伪造截图。
