# 我的 AI 实践手记

记录如何借助 AI，把生活和工作中的想法做成可以使用、可以检查的成果。每篇手记交代需求、实施过程、本人和 AI 的分工，也说明哪些已经验证、哪些还只是目标。

这里分享方法，不把一次成功写成长期保证，不把方案设计写成实测结果。

## 怎样使用这些手记

1. 先看每篇的“成果”和“验证证据”，判断它是否适用于你的需求。
2. 按实施步骤，用自己的环境和有权使用的素材尝试。
3. 记录观察结果、失败状态和恢复动作，再补充自己的结论。

新案例可从 [案例模板](templates/case-template.md) 开始。素材边界和发布检查见 [公开内容检查](PUBLICATION.md)。
