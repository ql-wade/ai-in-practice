# 历史案例与诊断原则：本地 Wan 短视频

[返回技能](../SKILL.md) · [对应案例](../../../cases/local-ai-video/README.md)

以下是一次真实本地运行的观察记录，以及从本案例抽出的可复用诊断原则。它不是通用性能保证，也不是已经验证的身份锁定方案。公开文本不包含源图、成片文件、私有引用、内部 prompt ID 或电脑专属路径。

## 已观察到的环境

- Windows；RTX 3090，24 GB 显存；系统内存 64 GB。
- ComfyUI；Wan2.2 A14B I2V，Q5_K_M 双专家；UMT5 FP8；Wan2.1 VAE；CPU 卸载。
- 场景是马斯克形象与钢铁侠在重庆火锅店抢着买单的 AI 虚构油画。它不是现场记录、代言或真人/角色真实行为。
- 先做约 3 秒的分段，再用末帧续接。首版原始视频为 12.25 秒、480×832、16 FPS、196 帧、无声音。
- 随后剪辑为 9.625 秒、154 帧，带 AAC 48 kHz 立体声音轨、中文字幕和贯穿全片的“AI 虚构”标识。
- 本次未新增付费 API 或租用 GPU；这不等于免费或无成本，仍有本地硬件、电力和时间成本。

## 结果与边界

管线实际跑通并产出可播放文件，但身份和画风出现漂移，动作与故事因果不够清楚，音效电平偏低。裁剪避开脸只能改变画面，不是修复身份一致性；因此不能称为高清成熟产品或验收成片，只能称为预览/待修订。

源图字节哈希与尺寸核验通过；生成画面做过抽帧检查，但人物一致性未通过。公开版不提供具体值和私有文件引用。技术、视觉、故事三层结论见对应案例和 [成片验收](acceptance.md)。

## 可复用诊断原则

### 场景母版与镜序

- 把关键结构写成不可混用的世界规则。落地排水墙与悬浮实心墙不是同一结构的两个景别；发现冲突先回场景母版，不靠提示词或剪辑掩盖。
- 空间探索片先冻结当前选定的信息推进顺序，例如发现、接近、墙下、退出、远望。这个顺序只是一种方案，不是所有片子的固定模板；按已选方案逐镜核对功能。
- 收束远望后不能无动机返回出口，也不能为了时长插入未验重复镜头。若镜头有意切换空间，明确记录切镜动机；若要求连续运动，使用已核验的相邻状态而不是每段从同一静图重新起步。

### 运镜与控制信号

- 对照相机目标同时读取正负提示词、节点输入和输出视频。要求向前推镜时，排查 locked/static camera、no parallax 等矛盾约束；主体保持刚性不等于相机必须锁定。删除冲突只是候选修复，不等于已经实现推镜。
- 核对控制信号确实连接到当前采样分支、实际加载权重、模型、量化及节点版本、启用状态与强度，而非只看图上节点存在。轨迹须查看实际点坐标、归一化或像素单位、帧索引、近远景点的速度关系、缩放裁切后位置、插值与出界。
- 区分相机视差与主体几何漂移。对照刚体轮廓、内部边线和遮挡关系，选近树、草坡、远树等静止深度参照，检查相对位移、速度趋势和前后遮挡是否符合机位。树叶、水纹自身运动另行排除；低光流可能是静止，高光流可能来自植被或水面，阈值不能独自证明前移或刚体失真。

### 短样扩长与连续接续

- 短样通过不代表较长版本通过；运动累积、轨迹出界、后段漂移和伪影可能改变结果。保留已通过短样及配置和哈希，写清延长假设、允许新增成本、全区间失败判据与回退点。
- 只做最短必要扩展，检查真实配置及全部输出帧，再在实际相邻镜中重验组接和正常速度播放。长版失败不能继承短样的 pass；精确裁掉坏尾后仍须重验保留的完整区间。针对性重试遵守既定预算，无改善即回退或改镜头设计。
- 连续接续要限制接力链长度，逐段回场景母版检查；不要延续已漂移的尾帧。单尾帧约束位置但不包含速度历史，固定 seed 或同 prompt 也不等于共享场景几何。不要跨有意硬切插值，也不要用循环、冻结或慢放凑长。
- 分开记录机械通过、单镜通过、相邻组接通过和整片正常播放/听音状态；其中一项通过不能替代其他项。

## 未测试的提升方向

下面只是调研候选，不能写成这次已经验证的结果：

- 优先测试 Wan2.2 原生首尾帧能力，观察端点约束是否改善动作连续性。
- 分别评估 VideoX-Fun 的 FunInP、Camera、Control 方向对端点、运镜和动作的约束作用。
- 评估 Phantom 的多主体方向和 VACE 的控制能力；它们是候选控制路线，不等于已经实证锁脸。
