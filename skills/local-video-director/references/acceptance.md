# 成片验收

[返回技能](../SKILL.md)

“能播放”只是技术层的一个结果。最终文件要分别经过技术、视觉和故事三层判断；任何关键层未通过，都应标为“预览/待修订”。

## 技术层

- [ ] 最终导出可以从头到尾解码，时长、宽高、帧数和 FPS 与记录一致。
- [ ] 每个拼接点没有意外黑帧、冻结、跳帧或音画错位。
- [ ] 声音轨道实际存在；已测量电平并试听全片，确认听得到、无明显削波、不压过对白。AAC 或非零响度本身不能证明声音合格。
- [ ] 中文字幕逐句校对，字体、断行、安全边距、阅读时间和遮挡合适。
- [ ] AI 生成标识从第一帧、转场到最后一帧都存在；不能只在封面或片尾标记。

## 视觉层

- [ ] 每镜的首帧、中段、尾帧都与原始参考对照。
- [ ] 身份、服装、画风、手/肢体、关键道具、物理关系和画面边界符合目标。
- [ ] 所有拼接边界没有身份、姿态、光线或风格的不可接受跳变。
- [ ] 不把裁脸、遮挡或字幕盖住问题当作修复；后段变脸仍判身份未通过。

## 故事层

- [ ] 观众能看出角色目标、动作/冲突、反应和可见结果。
- [ ] 动作确实发生，字幕只是辅助理解，不替不存在的动作编故事。
- [ ] 时长、节拍和镜头顺序支持“铺垫 → 动作/冲突 → 结果/笑点”。

## 交付记录

记录每层的 `通过 / 待修订 / 未验证`，并写出镜头、时间点和原因。交付时同时说明原生生成尺寸、剪辑后尺寸、声音状态、字幕与 AI 标识状态，以及尚未修复的缺陷。不要用高清、成熟产品、锁脸或全自动等词替代证据。
