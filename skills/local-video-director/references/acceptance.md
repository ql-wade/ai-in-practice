# 成片验收

[返回技能](../SKILL.md)

“能播放”只是技术层的一个结果。最终文件要分别经过技术、视觉和故事三层判断；声音与感知证据另行记录。任何关键层未通过或未验证，都应标为“预览/待修订”。

## 先记状态与净时长

- 分开记录候选池总量、实际选用 EDL、组接已验净时长和生成中计划。单镜通过但未进入时间线，或未通过相邻组接，只算候选，不算净交付。
- 记录零基、尾帧排除的 in/out、保留帧数和版本；重叠转场扣除重叠。替换净增为新选用且组接已验的时长，减去被移除区间，再减去新增重叠；不能把替换段全长当补足。
- 约一分钟是近似创作目标而非逐帧硬门槛。没有严格下限时，不为接近边界的一帧差异重生成，也不靠慢放、冻结、重复或无意义补帧凑长。记录拒收清单，不能重新引入失败版本。

## 扩展与组接

- 短样通过不等于长版通过。运动累积、轨迹出界、后段漂移和伪影可能改变结果；保留短样及其配置和哈希，写清延长假设、允许新增成本、全区间失败判据和回退点。
- 只做最短必要扩展，检查真实配置和全部输出帧，再在实际相邻镜中重验组接和正常速度播放。长版失败不能继承短样的 pass；精确裁掉坏尾后仍须重验保留的完整区间。
- 机械通过、单镜通过和整片组接通过是独立门槛。技术切点无黑闪不代表运动、空间或节拍丝滑；不要跨有意硬切插值。

## 技术层

- [ ] 最终导出可以从头到尾完整解码，容器与编码在目标渠道兼容，时长、宽高、帧数和 FPS 与记录一致。
- [ ] 每个拼接点没有意外黑帧、冻结、跳帧或音画错位；音视频轨时长和时间戳合理。
- [ ] 需要声音时，音轨实际存在且有效声长覆盖应有画面；测量整体响度、峰值或 true peak，并检查无明显削波。AAC 或非零响度本身不能证明声音合格；源音轨正确也可能被错误增益或封装破坏。
- [ ] 中文字幕逐句校对，字体、断行、安全边距、阅读时间和遮挡合适。
- [ ] 对需要 AI 标识的交付版，标识从第一帧、转场到最后一帧都符合用户和目标平台的当前要求；若交付干净母版，记录它不含后加角标但保留原生来源信息。不要把一次平台规则当成长期通用规则。

## 视觉层

- [ ] 每镜的首帧、中段、尾帧、动作转折密集帧都与原始参考对照。
- [ ] 身份、服装、画风、手/肢体、关键道具、物理关系、遮挡、视差和画面边界符合目标。
- [ ] 所有拼接边界前后各检查一段，确认没有身份、姿态、光线、空间方向或风格的不可接受跳变。
- [ ] 对空间运动，区分相机视差与主体几何漂移；不能把墙体弯曲伸缩当推进，也不能把合理透视变化全判为变形。
- [ ] 不把裁脸、遮挡或字幕盖住问题当作修复；后段变脸仍判身份未通过。

## 故事层

- [ ] 观众能看出角色目标、动作/冲突、反应和可见结果；景观或空间片则能看出尺度、结构、遮挡/视差和空间推进。
- [ ] 动作确实发生，字幕只是辅助理解，不替不存在的动作编故事。
- [ ] 时长、节拍和镜头顺序支持当前设计的铺垫 → 动作/冲突 → 结果/笑点，或已选的空间探索顺序；不为时长插入未验重复镜头。
- [ ] 叙事因果和有意切镜清楚；没有跨硬切的伪连续或用循环、冻结、倒放、慢放掩盖素材不足。

## 声音与感知证据

- [ ] 逐帧检查、技术指标、实际正常速度观看和真实听音分别记录，不能从联系表、解码、波形或响度推导感知验收通过。
- [ ] 有角色对白时，台词、speaker、停顿、说话者归属和对白起止清楚；字幕加笑声不算完整角色对白。未做口型同步不能声称 lip-sync。
- [ ] 完整正常速度播放最终导出，确认切点、空间运动、音量、音画同步和完整声音，而不是只看逐帧抽样或中间文件。
- [ ] 无法播放或听音时，先找受支持路径；仍不可用就标“听感未验”，请用户完成最小人工步骤：正常速度完整播放附件一次，重点确认标出的切点、空间运动、音量和音画同步。请求人工检查不等于检查已完成。

## 交付记录

记录每项的 `通过 / 待修订 / 未验证`，并写出镜头、时间点、版本和原因。交付时同时说明候选池总量、实际 EDL、组接已验净时长、原生生成尺寸、剪辑后/派生尺寸、帧率、帧数、文件大小、声音状态、字幕与 AI 标识状态，以及尚未修复的缺陷。保留原始母版；原尺寸兼容副本与缩小聊天副本是不同交付层级，不把后者冒充母版或原尺寸，不把低分辨率文件冒充 4K。不要用高清、成熟产品、锁脸或全自动等词替代证据。
