# 本地视频生成与剪辑

交付真正发生动作、有铺垫和结果、角色与画风可信的短片。把“技术可播放”“视觉一致”“故事成立”分开验收；只解码成功不能称为验收成片。

## 1. 锁定创作目标与可用环境

- 从需求中提取角色、场景、画风、笑点或情绪、时长、比例、字幕与声音要求。保留用户已经选定的组合，缺少关键决定才询问，不悄悄替换角色或风格。
- 先写简短分镜：每镜的原始参考、视觉摆位、可见动作、结果、拟用秒数，以及镜间如何衔接。总时长是目标而不是硬凑；平移或缩放静图不能冒充真正的图生动作。
- 先确认实际执行环境，再做最小检查：操作系统、GPU/显存、可用磁盘、ComfyUI 服务或队列、模型和输入目录。不要从某个工具缺失推断另一台用户设备不可用。
- 分开验证云端或原生文件读取、Windows 执行和跨环境原文件传输。复用已批准的安装、模型和运行任务；不重复下载或启动同一作业，也不为本任务修改其他项目的原环境。新安装、付费服务、发布和额外插件不是默认授权。

## 2. 生成或导入原始参考图

- 用用户明确选定的人物与风格诚实描述，生成或读取参考图后，先检查脸、服装、构图、手和关键道具。
- 工具若返回原因不明的审核错误，如实报告范围；不可据此声称整类内容禁止，也不可用伪装或隐去身份的描述规避限制。只在允许范围内采用透明、实质性修订。
- 将原始图像字节保存到用户有权使用的原生文件存储，再通过受支持的文件物化方式传至执行环境；不要拿页面截图代替原图。
- 验证源与落地文件的 SHA-256、尺寸和格式，再复制入 ComfyUI 输入目录。传输失败时读 [传输与恢复](references/transfer-and-recovery.md)，不要使用安全绕过或分块编码技巧。

## 3. 先短样片，再逐镜生成

- 读取实际可用节点与模型，选择适合显存的 Wan I2V 工作流，不臆造节点名、参数或通用性能保证。已有环境经验只作为观察记录，见 [历史案例](references/observed-case.md)。
- 先生成一段短样片，立刻对照原图查看首、中、尾帧和实际运动，确认身份、风格与动作可用后才扩展。默认每镜从原始参考或经核验的原始参考衍生图独立生成；不要把已经漂移的尾帧不断串成更长视频。参考刷新可以降低累积漂移，但不保证身份锁定。
- 为每次提交保存检查点：执行环境、源图引用与哈希、workflow、prompt ID、种子、模型/量化/版本、提示词、原生尺寸、帧数/FPS、状态、输出位置和验收结论。重连先查队列、历史与输出，避免重复作业。
- 失败时定位到具体镜头、时间点和原因，只重做必要片段。停止依赖不合格素材的后续生成；需要超出授权的资源时先询问。

## 4. 剪辑为可读的故事

- 按“铺垫 → 动作/冲突 → 结果/笑点”选择可用片段，裁切停滞和重复，统一比例与 FPS 后拼接；按实际需要使用干净切镜或短过渡。保留角色和动作因果，不通过裁脸、遮挡或字幕掩盖变脸。
- 字幕按节拍出现，检查中文字体、断行、安全边距、阅读时间和遮挡。AI 生成标识贯穿完整成片，包括第一帧、转场和最后一帧。
- 只使用用户要求且有权使用的配乐、音效或声音；不得默认克隆真人声音或使用未授权音乐。检查音轨实际存在，测量电平，并实际试听全片确认听得到、无削波、不过分抢对白。只有 AAC 轨道或非零响度不等于声音合格；不能试听就明确保留未验收状态。
- 常规交付可选兼容的 MP4/H.264、yuv420p、AAC 和 fast-start，仍以目标平台与用户要求为准。如做放大，分别报告生成原生分辨率和交付分辨率。

## 5. 三层验收与交付

交付前逐项使用 [成片验收](references/acceptance.md)，检视最终导出而不是只检视原始片段。

- 技术：可解码、时间/尺寸/FPS 正确、音轨与音量可用、字幕和全程 AI 标识完整。
- 视觉：逐镜首/中/尾帧与所有拼接边界对照原图，检查身份、服装、画风、手/肢体、道具、物理与连续性。任何后段变脸仍判身份未通过，即使最终裁掉该脸或被字幕遮住。
- 故事：动作真正发生，角色目标与反应清晰，有可见结果，字幕辅助而不是替没有发生的动作编故事。

将最终原始 MP4 通过受支持的文件附件或用户指定的公开渠道交付，不以截图、私有下载 URL 或只存在本机的路径替代。先确认用户能打开。说明实际时长、原生/交付尺寸、声音、通过项和剩余缺陷；任一关键项未通过，明确叫“预览/待修订”，不能叫“验收成片”。保留可复现检查点和需要返修的镜头位置。

本公开副本不包含私有 Library/Space 链接、文件 ID、账号资料、内部会话材料或电脑专属绝对路径，也不提供绕过安全限制、获取登录态或分块上传的技巧。遇到未知的 403 或权限结果，只记录该次请求的范围，不把它泛化为系统结论。
